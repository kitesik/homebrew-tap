# kitesik Homebrew Tap

## ChiiBar 설치

Homebrew가 설치되어 있다면 아래 한 줄로 설치합니다.

```bash
brew install --cask kitesik/tap/chiibar
```

macOS 14 이상, Apple Silicon과 Intel Mac 공용입니다.
설치 후 응용 프로그램에서 ChiiBar를 실행하세요.
첫 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 선택하세요.

업데이트:

```bash
brew update && brew upgrade --cask kitesik/tap/chiibar
```

삭제 (친구와 집 저장 데이터는 유지):

```bash
brew uninstall --cask chiibar
```

[앱 소개와 설치 안내](https://github.com/kitesik/ChiiBar)
